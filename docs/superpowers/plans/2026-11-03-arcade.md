# Arcade Ruins Implementation Plan

Goal: extend Projeto Moedas into four playable run-and-gun stages using the supplied bright pixel-art ruins reference.
Architecture: preserve the existing Arcade/Peewee contracts; separate assets, campaign rules and game views. Python Arcade 3.3.3, Peewee, Pillow for exact pixel grids.

## Approved direction
Side-scrolling pixel art, bright skies, overgrown stone ruins and wooden bridges. Four stages, incremental patrol/drone/shooter pressure and a final boss. AK47 with magazine/reload, particles, muzzle flash, casings, sound, damage flash and short shake. Coins remain relevant to score and completion. Original course requirements remain binding.

## Tasks
- [x] Campaign rules and tests: reachable authored routes, progressive enemies, weapon cooldown/reload, one-way completion and damage invulnerability.
- [x] Assets: exact 96x128 player frames (idle, jump, eight walk), enemy frames, 48px terrain tiles, sky/ruin background and original synthesized WAV effects.
- [x] Runtime: fixed-step physics, scrolling camera, four stages, combat and boss, coins, transitions, pause, sound toggle and reduced effects.
- [x] Persistence/UI: preserve Peewee schema, Top10 snapshot in constructor, keyboard name capture with error handling, menu/help/credits and final score.
- [x] Verify: behavioral tests, headless real Arcade smoke tests and rendered gameplay screenshot; document installation, controls and requirement mapping.

Review focus: held keys on view changes; frame-rate-independent simulation; unreachable pickups; duplicate score insertion; mute/no audio hardware; boss/end transition only once; no tracked database modification.

## Verification
13 behavioral and real Arcade/EGL integration tests pass. Game/menu/combat rendered and visually reviewed.
